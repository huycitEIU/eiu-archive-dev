# ADR 001

# Using Cloudflare R2 for Object Storage

- Status: Accepted
- Date: 2026-07-30

## Context

The system needs a reliable object storage solution for storing user-uploaded files such as images, documents, and other static assets.

The storage solution should satisfy the following requirements:

- High durability and availability
- Scalable with increasing storage demands
- Compatible with standard S3 APIs
- Low operational overhead
- Cost-effective, especially for bandwidth-intensive workloads
- Easy integration with the existing backend infrastructure

Several alternatives were considered:

- Amazon S3
- Google Cloud Storage
- Azure Blob Storage
- Cloudflare R2

## Decision

We will use **Cloudflare R2** as the primary object storage service.

The reasons for this decision are:

- S3-compatible API allows easy integration with existing SDKs and tools.
- No egress bandwidth charges when serving objects through Cloudflare.
- Lower storage costs compared to many traditional cloud storage providers.
- Automatic scalability without infrastructure management.
- Seamless integration with Cloudflare services such as CDN, Workers, and custom domains.
- Suitable for storing static assets, backups, and user-generated content.

## Consequences

### Positive

- Reduced storage and bandwidth costs.
- Simplified infrastructure management.
- High durability and availability provided by Cloudflare.
- Easy migration due to S3 API compatibility.
- Improved global performance when combined with Cloudflare's edge network.

### Negative

- Vendor lock-in to Cloudflare services may increase over time.
- Some advanced Amazon S3 features are not available or behave differently.
- Applications relying on AWS-specific storage features may require adaptation.
- Team members need familiarity with Cloudflare's dashboard and management tools.

### Risks

- Future pricing or feature changes from Cloudflare could affect operating costs.
- Migration to another storage provider would require data transfer and configuration changes, although S3 compatibility helps reduce migration complexity.
